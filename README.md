## 🌷 02. Deskripsi Praktikum

Praktikum 6 merupakan kegiatan praktikum mata kuliah Pemrograman Web yang membahas JavaScript DOM (*Document Object Model*) dan *Event Handling*.

## 📚 10. Pertanyaan Evaluasi

### 1. Apa yang dimaksud dengan DOM dan apa manfaatnya?

DOM (*Document Object Model*) adalah representasi dokumen HTML dalam bentuk objek yang dapat diakses dan dimanipulasi oleh JavaScript. DOM memungkinkan program memilih elemen, mengubah konten, mengatur kelas CSS, serta merespons tindakan pengguna.

### 2. Apa perbedaan `getElementById()`, `querySelector()`, dan `querySelectorAll()`?

`getElementById()` memilih elemen berdasarkan ID. `querySelector()` memilih elemen pertama yang sesuai dengan selector CSS, sedangkan `querySelectorAll()` memilih semua elemen yang sesuai dengan selector CSS.

### 3. Apa fungsi `addEventListener()` dan sebutkan tiga contoh event?

`addEventListener()` menghubungkan event dengan fungsi yang dijalankan ketika event terjadi. Contohnya adalah `click`, `input`, dan `submit`.

### 4. Mengapa `event.preventDefault()` digunakan pada event submit form?

`event.preventDefault()` mencegah tindakan bawaan browser ketika formulir dikirim, sehingga JavaScript dapat memvalidasi input dan menampilkan pesan tanpa halaman langsung dimuat ulang.

### 5. Apa perbedaan `textContent` dan `innerHTML` dari sisi penggunaan dan keamanan?

`textContent` digunakan untuk membaca atau mengubah teks biasa, sedangkan `innerHTML` digunakan untuk membaca atau mengubah isi elemen dalam bentuk markup HTML. `textContent` lebih aman untuk menampilkan input pengguna karena tidak menafsirkan teks sebagai markup HTML.

### 6. Bagaimana `classList.toggle()` membantu mengubah tampilan elemen?

`classList.toggle()` menambahkan kelas CSS jika belum ada atau menghapusnya jika sudah ada. Fitur ini dapat digunakan untuk menandai tugas selesai atau menyembunyikan dan menampilkan paragraf.

### 7. Sebutkan minimal tiga skenario pengujian validasi form.

1. Data nama, email, dan sesi valid sehingga pendaftaran berhasil.
2. Nama kurang dari tiga karakter sehingga muncul pesan kesalahan.
3. Email tidak valid sehingga muncul pesan kesalahan.
4. Sesi workshop belum dipilih sehingga pengguna diminta memilih sesi.
